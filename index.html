Codepyquent ORM

An active-record ORM that feels like Eloquent

Chainable queries, relationships, eager loading, scopes, accessors, and collections — all the ergonomics you'd expect, powered by SQLAlchemy under the hood.

app/Models/User.py
from codepy.orm import Model

class User(Model):
    __table__ = "users"

    fillable = ["name", "email", "password"]
    hidden   = ["password", "remember_token"]
    casts    = {"email_verified_at": "datetime",
                "is_admin": "boolean"}

    def posts(self):
        return self.has_many(Post)

    def profile(self):
        return self.has_one(Profile)
query_examples.py
# Chainable query builder
users = User.query() \
    .where("active", True) \
    .where("age", ">", 18) \
    .order_by("created_at", "desc") \
    .paginate(15)

# Single-record helpers
user = User.findOrFail(1)
user = User.firstOrCreate(
    {"email": "a@b.com"},
    {"name": "Jane"}
)

# Eager loading prevents N+1
users = User.query().with_("posts").get()

Roadmap

Six phases from foundation to launch

A suggested build order that ships a working app at each milestone, rather than front-loading everything.

1

Foundation

Project layout, DI container, config/env, kernel bootstrap, basic router + controllers, Jinja2 views, dev server, and scaffolding commands.

Ships: A working app that serves pages with routes, controllers, and views.
2

Database

SQLAlchemy integration, Codepyquent models, query builder, relationships, scopes, collections, migrations engine, seeders, and factories.

Ships: Full ORM + migrations + seeding matching Eloquent's DX.
3

HTTP Ergonomics

FormRequest validation, API Resources, middleware pipeline, sessions, CSRF, throttle, named routes, route model binding, and response helpers.

Ships: Production-quality request/response cycle with security middleware.
4

Auth & Authorization

Session and token guards, password hashing, reset flow, email verification, gates, policies, and auth scaffolding.

Ships: Complete auth system with fine-grained authorization.
5

Extended Subsystems

Events, listeners, queues, mail, notifications, filesystem, cache, Forge directives, localization, and task scheduling.

Ships: Full batteries-included framework with queues, mail, and scheduling.
6

DX & Documentation

Complete CLI, tinker REPL, route listing, debug error page, testing harness, Sail-equivalent Docker, docs site, and demo app.

Ships: Polished, documented, testable framework ready for adoption.
