# Craft AI Agents Registry

This directory contains the definitions and prompts for the specialized AI Agents designed to collaborate on this codebase.

## Active Agents

* **[Craft Architect](file:///d:/data/www/craft%20engine/.agents/agents/codepy-architect.md):** Focuses on system architecture, database schema, performance bottlenecks, and design integrity.
* **[Craft Developer](file:///d:/data/www/craft%20engine/.agents/agents/codepy-developer.md):** Generates, refactors, and maintains MVC backend components (`app/Http/Controllers`, `app/Models`, `app/Services`).
* **[Craft Tester](file:///d:/data/www/craft%20engine/.agents/agents/codepy-tester.md):** Writes and executes test suites to validate code correctness and verify security mitigations.
* **[Craft Data Guardian](file:///d:/data/www/craft%20engine/.agents/agents/craft-data-guardian.md):** Enforces absolute data persistence, soft-deletes, forward-only migrations, and blocks destructive CLI/database operations.
