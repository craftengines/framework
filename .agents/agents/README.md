# Codepy AI Agents Registry

This directory contains the definitions and prompts for the specialized AI Agents designed to collaborate on this codebase.

## Active Agents

* **[Codepy Architect](file:///d:/data/www/codepy/.ai/agents/codepy-architect.md):** Focuses on system architecture, database schema, performance bottlenecks, and design integrity.
* **[Codepy Developer](file:///d:/data/www/codepy/.ai/agents/codepy-developer.md):** Generates, refactors, and maintains MVC backend components (`app/Http/Controllers`, `app/Models`, `app/Services`).
* **[Codepy Tester](file:///d:/data/www/codepy/.ai/agents/codepy-tester.md):** Writes and executes test suites to validate code correctness and verify security mitigations.
